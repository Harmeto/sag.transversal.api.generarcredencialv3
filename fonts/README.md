Fuentes adicionales para el motor Typst (se cargan además de las del sistema y las embebidas).
En local, macOS ya provee Arial y Helvetica. En la imagen Docker se instala `fonts-liberation`
(Liberation Sans es métricamente compatible con Arial). Para plantillas con fuentes propias
(p. ej. gobCL o Asap Condensed de plaguicidas) copiar aquí los .ttf/.otf/.woff.
